# 12. IMPORTANT VERIFIED PWA ↔ CORE DETAILS

## 12.1 Shared authentication

`core.js` يعرّف `RW_Auth` ويستعيد الجلسة من Supabase Auth، ويقرأ `users` للسياق المساعد، ويحوّل Owner إلى `isOwner`، كما أن `checkPermission()` يعتبر `isOwner` أو `permissions=['*']` صلاحية شاملة على مستوى الواجهة.

هذا يفسر لماذا يجب حماية Owner contract بدقة.

## 12.2 Shared local/offline layer

`core.js` يعرّف `RW_DB` فوق Dexie، ويستخدم قواعد local schema مشتركة لعملاء/أصناف/مخزون/فروع/طلبات/pending updates.

## 12.3 Shared backend boundary

`core.js` يعرّف `RW_API.call()` لاستدعاء:

```text
SUPABASE_URL/functions/v1/<functionName>
```

بـBearer token من الجلسة الحالية.

إذن الواجهات المنفصلة ليست بدائل مستقلة للـEdge Functions.

## 12.4 Service-worker path

`register-sw.js` يسجل `./sw.js` داخل موقع Current/PWA ويقوم بالتحديث الدوري ويتعامل مع `controllerchange`. لذلك أي غموض Browser Runtime يجب أن يشمل cache/SW، لا الـHTML فقط.
