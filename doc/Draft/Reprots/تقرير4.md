## 3. التمييز الحاسم: 404 قبل تنفيذ SW

الطلب:

`/companies/sw.js → 404`

هو طلب الحصول على **ملف JavaScript الخاص بالـService Worker نفسه**.

إذا أعاد الـorigin/CDN `404` فلن يبدأ تنفيذ `install` أو `activate` أو `fetch` في هذا الملف أصلًا.

لذلك:

`SW source defect` ≠ `SW resource placement/routing defect`

وتحديث محتوى `Current/PWA/sw.js` وحده لا يثبت أن `/companies/sw.js` أصبح موجودًا في الـartifact المنشور.

هذه نقطة تم الحفاظ عليها صراحةً حتى لا يتحول إصلاح source إلى ادعاء كاذب بإغلاق runtime.
