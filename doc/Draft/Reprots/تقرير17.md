# 4. LOST-01 — Notification Panel

## المسؤولية المفقودة

المسؤولية ليست Module مفقودة. الـmodule موجودة، والـbadge موجود، و`markAllRead` موجودة، كما أن `markRead` و`_clickNotif` موجودتان في طبقة التوافق اللاحقة.

**الفقد الحقيقي هو أن الـactive `showPanel()` لا يعيد توصيل هذه الوظائف بالواجهة.**


# 6. LOST-03 — Password Visibility UI

## الحالي المعيب

المفقود هو زر الاستدعاء في HTML.

ابحث عن المقطع الحالي كاملًا:

```html
<div class="rw-form-group"><label class="rw-form-label" for="rw-password">كلمة المرور</label><input id="rw-password" class="rw-input" type="password" autocomplete="current-password"></div>
```

احذفه بالكامل واستبدله:

```html
<div class="rw-form-group">
  <label class="rw-form-label" for="rw-password">كلمة المرور</label>
  <div class="rw-password-wrap">
    <input id="rw-password" class="rw-input" type="password" autocomplete="current-password">
    <button type="button" class="rw-password-toggle" aria-label="إظهار كلمة المرور" title="إظهار كلمة المرور" onclick="window.togglePasswordVisibility('rw-password', this)"><i class="fa-solid fa-eye"></i></button>

```

وأضف فوق `.rw-login-options`:

```css
.rw-password-wrap{position:relative;width:100%}
```
