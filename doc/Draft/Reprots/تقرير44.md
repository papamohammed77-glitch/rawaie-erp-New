A constrained assistant cannot truthfully perform:

```text

```

Yet it can still perform high-value work if it is constrained to:

```text

Exact file comparison
Commit-snapshot comparison
Historical contract analysis
Patch design
Surgical source edits

Evidence-based handoff
```

The critical design rule is therefore:

```text

→
SMALLER CLOSURE UNITS

NOT

LIMITED TOOLS
→
LOWER EVIDENCE STANDARDS
```


