# 13. الدوال المعيبة التي يجب أن يستهدفها التعديل الجراحي

هذه هي الدوال/المقاطع التي تمثل الـactual defect.

## DEFECT-A — `renderDashboard`

الدالة الحالية:

```javascript
async function renderDashboard(){ ... }
```

هذه ليست Main2 Dashboard.

### التعليمات الجراحية

ابحث عن:

```javascript
async function renderDashboard(){
```

ولا تحذفها الآن.

المطلوب تغيير **الـrouting الذي يستدعيها** وليس حذف implementation نفسها، لأن consumer tracing الكامل خارج نطاق هذه الجولة لم يثبت أن لا أحد يستخدم اسمها مباشرة.

ابحث عن هذا السطر/المقطع:

```javascript
var actions={dashboard:renderDashboard,
```

واحذف فقط:

```javascript
dashboard:renderDashboard,
```

واستبدله بـ:

```javascript
dashboard:function(){return RW_Dashboard.render();},
```

السبب التقني:

```text
RW_Dashboard
```

يُعرّف لاحقًا في الملف، لذلك لا تستخدم reference مباشر أثناء إنشاء `actions`; استخدام wrapper function يؤجل resolution إلى وقت التنفيذ.
