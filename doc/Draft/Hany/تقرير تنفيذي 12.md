## 4. لماذا تكررت المحاولات الفاشلة تاريخيًا

تمت مصالحة الأخطاء التاريخية بدل تكرارها.

### 4.1 Clean-room reconstruction

التشغيل التاريخي `99726102288` كان غير صالح كمرجع تنفيذ ناجح، ولم ينتج artifact يمكن الاعتماد عليه من endpoint المتاح.

وفق السجلات السابقة، ظهرت أيضًا مشاكل في reconstruction executor، منها syntax/indentation failure ومسارات checkout غير موثوقة.

الاستنتاج: **إعادة reconstruction ليست الحل لهذا العيب.**

### 4.2 Zero-job workflow

التشغيل `33508781448` سبق أن ظهر بحالة صفر Jobs، وتمت إعادة المحاولة دون إنتاج تنفيذ صالح.

تم تحديد السبب التشغيلي المهم: بعض الـworkflow conditions كانت تمنع إنشاء Job فعلي، لذلك نجاح إنشاء run أو trigger لم يكن يعني execution.

هذا المسار لم تتم إعادته في P131.

### 4.3 Blob write blocker

GitHub `update_file` يتطلب full-file replacement، بينما target عبارة عن monolithic HTML كبير.

كما تعذر materialize للـblob داخل container عبر شبكة مباشرة.

لذلك تم رفض إعادة بناء الملف من مقتطفات أو إعادة إرساله بالكامل، لأن ذلك قد يدمر أجزاء سليمة من target.

الحل الذي ثبت عمليًا كان تشغيل patch داخل GitHub runner نفسه، حيث يستطيع runner checkout الملف الكامل وتعديل anchor موضعيًا.

### 4.4 البحث عن artifact تاريخي بديل

تم العثور على `Current/PWA/main/main10.md` ونسخ Current/Original التاريخية، لكن هذه artifacts modules وليست replacement آمنًا كاملًا لـ`New-main`.

استبدال `New-main` بها كان سيكون destructive regression، ولذلك تم رفضه.

## 16. أخطاء هذه الجولة

### الخطأ 1 — تفسير غياب run من wrapper على أنه غياب تنفيذ
في البداية، `fetch_commit_workflow_runs` لم يُظهر run للـPR commit، ولكن check-runs API كشف أن workflow jobs كانت تعمل فعليًا.

**الإصلاح:** عند وجود تعارض، يجب cross-check مع check-runs/jobs بدل الاعتماد على wrapper واحد.

### الخطأ 2 — فتح PR أدى إلى تشغيل workflows تاريخية أخرى
فتح PR نفسه شغّل `reconstruct`, `gold_reconstruction`, `inventory`.

**التقييم:** لم تفسد target في هذه الجولة، لكنها أثبتت أن event topology للمشروع أكبر من الـworkflow المقصود.

**التوصية:** أي future PR يجب أن يحمل workflow isolation واضحًا أو paths/conditions تمنع jobs التاريخية غير ذات الصلة من العمل.

### الخطأ 3 — افتراض أن وجود historical artifact يعني أنه replacement صالح
تم العثور على main10 وغيره، لكن تم رفض استخدامها كبديل كامل.
