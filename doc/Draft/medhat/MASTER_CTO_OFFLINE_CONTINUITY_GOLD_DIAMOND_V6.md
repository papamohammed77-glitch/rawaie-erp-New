```text

BLOCKING UNKNOWN
```

إذا كان غير مؤثر:

```text
RECORD
CONTINUE
```

إذا كان مؤثرًا:

```text
BLOCKED — EXACT EVIDENCE REQUIRED
```

مع تحديد:

```text
exact file
exact function
exact contract
exact DB result
exact screenshot/log
```

لا تقل “أرسل المزيد من الملفات” بشكل عام.
